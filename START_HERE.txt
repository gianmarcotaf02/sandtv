🔧 CONFIGURAZIONE

Nel Player.tsx (linea ~85), personalizza:

const liveEdgeManagerRef = useRef(getLiveEdgeManager({
  delayThreshold: 2.5,        // Mostra bottone se > X secondi
  delayThresholdLow: 1.5,     // Nascondi se < X secondi (isteresi)
  debounceMs: 500,            // Stabilità controlli
  minBufferForLive: 0.8,      // Buffer minimo dal live
  seekRetryAttempts: 3,       // Retry se fallisce
  enableDiagnostics: true,    // Log nella console
}));

Profili preconfigurati disponibili per:
  🏃 Sport (latenza minima)
  🎬 Film/serie (qualità)
  📡 Rete instabile (robustezza)

🎬 ALGORITMI CHIAVE

1️⃣ RILEVAMENTO RITARDO
   delay = seekableEnd - currentTime
   if delay > 2.5s → MOSTRA bottone
   if delay < 1.5s → NASCONDI bottone
   else → MANTIENI STATO (isteresi)

2️⃣ ISTERESI (evita flickering)
   Gap di sicurezza tra 1.5-2.5s
   → No state change in questa zona

3️⃣ SEEK AL LIVE
   target = hls.liveSyncPosition - 0.8s buffer
   Retry automatico su timeout (max 3 volte)
   Ricarica buffer HLS
   Riproduci subito
