✅ ALGORITMI CHIAVE
────────────────────────────────────────────────────────────────────────────

1️⃣  RILEVAMENTO RITARDO
    delay = seekableEnd - currentTime
    if delay > 2.5s → MOSTRA bottone
    if delay < 1.5s → NASCONDI bottone
    else (1.5-2.5s) → MANTIENI STATO (isteresi)
    
2️⃣  ISTERESI (zero flickering)
    Gap di sicurezza tra 1.5-2.5s
    → Nessun cambio di stato in questa zona
    
3️⃣  SEEK AL LIVE
    target = hls.liveSyncPosition - 0.8s
    Retry automatico (max 3 volte)
    Ricarica buffer HLS
    Riproduci subito


🎬 COMPORTAMENTO FINALE
────────────────────────────────────────────────────────────────────────────

STATO NORMALE (in sync):
  delay: 0.5s
  → Bottone NASCOSTO ✅

STATO CON RITARDO:
  delay: 3.2s
  → Bottone ROSSO VISIBILE ✅

USER CLICCA BOTTONE:
  → Seek al live edge
  → Torna in sync
  → Bottone scompare
